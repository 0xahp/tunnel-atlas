What to run in 2026, and the path it takes

Pick your situation and compare the top setups. Each one shows who sees what on the way from your device to the website.

    No censorship: efficiency

    1. 1st · lowest battery: WireGuard, keepalive off

      Lowest battery cost of five VPNs in the only phone test (+32%), and silent when idle unless PersistentKeepalive is on. Leave keepalive off unless you're behind a strict NAT.

      Path (Classic VPN): Your device → Censor → VPN server → Website. Censor sees A VPN handshake; servers: 1 server; delay: +1 RTT (WireGuard).

      Good: Whole device, all traffic including UDP Built into operating systems Fast and efficient (kernel paths) Watch out: Obvious fingerprint: blocked in Iran and Russia, easy to block anywhere The VPN operator sees all your metadata

    2. 2nd · built in: IKEv2/IPsec (AES-GCM)

      Encrypts inside the system kernel, so no app process copies each packet. Lowest CPU in the 2020 lab (~42% at ~1 Gbit/s). Apple devices default to AES-CBC; AES-256-GCM needs a configuration profile.

      Path (Classic VPN): Your device → Censor → VPN server → Website. Censor sees A VPN handshake; servers: 1 server; delay: +1 RTT (WireGuard).

      Good: Whole device, all traffic including UDP Built into operating systems Fast and efficient (kernel paths) Watch out: Obvious fingerprint: blocked in Iran and Russia, easy to block anywhere The VPN operator sees all your metadata

    3. If you need a proxy: VLESS + REALITY (or Shadowsocks 2022)

      Low server CPU per GB in a 2026 field test; Shadowsocks 2022 was the fastest proxy protocol on loopback. The client app matters as much as the protocol.

      Path (REALITY self-steal): Your device → Censor → Your server → Website. Censor sees Visit to your own site; servers: 1 server; delay: +2 RTT (TCP + TLS).

      Good: No name/IP mismatch No third-party CDN to abuse Best field results in Iran and Russia, 2026 Watch out: Needs a domain again The server IP is still one block point; thousands of IPs at popular VPS providers were banned in Russia (Aug–Sep 2026)

    Efficiency rankings come from lab and phone tests of VPN protocols. Nobody has measured phone battery for proxy protocols.

    Censored country

    1. 1st · TCP: VLESS + REALITY + Vision, self-steal

      Reported working in Iran and Russia in 2026. Use your own domain with a real certificate as the handshake target, port 443, on a less popular hosting provider. Server: Xray or sing-box; own domain + Let's Encrypt.

      Path (REALITY self-steal): Your device → Censor → Your server → Website. Censor sees Visit to your own site; servers: 1 server; delay: +2 RTT (TCP + TLS).

      Good: No name/IP mismatch No third-party CDN to abuse Best field results in Iran and Russia, 2026 Watch out: Needs a domain again The server IP is still one block point; thousands of IPs at popular VPS providers were banned in Russia (Aug–Sep 2026)

    2. 2nd · UDP backup: Hysteria2 + Salamander

      Fast to start and strong on lossy links; reported working in Iran except Rightel (one user, Jun 2026). Useless where UDP is dropped. Server: Hysteria or sing-box; port hopping helps.

      Path (QUIC (Hysteria2)): Your device → Censor → Hy2 server → Website. Censor sees UDP / HTTP/3; servers: 1 server; delay: +1 RTT, 0 later.

      Good: Holds speed on lossy links Fast to start: 159 ms first byte in a field test No TLS-in-TLS Watch out: UDP is dropped or throttled on many networks 4–12× the server CPU of REALITY in a field test

    3. 3rd · fallbacks: XHTTP via CDN · AmneziaWG · Tor

      XHTTP or WebSocket through a CDN when your IP is blocked. AmneziaWG for a full-device VPN (built for Russia). With no server of your own: Psiphon, or Tor with Snowflake or WebTunnel.

      Path (CDN-fronted): Your device → Censor → CDN edge → Origin server → Website. Censor sees HTTPS to a CDN; servers: CDN + server; delay: +2–3 RTT, longer path.

      Good: Hides your server's IP Can work under allowlists that include CDN ranges XHTTP can split upload and download paths Watch out: Slower start (≈800 ms first byte in a field test) The CDN sees request metadata and has rules (100 s idle timeout)

    Rotate server IPs if they get blocked. In Turkmenistan any foreign IP gets banned after moderate traffic, whatever the protocol.

    Shutdown or allowlist

    1. 1st: Relay inside the country

      During allowlists the protocol matters less than the IP. A relay in a domestic data-centre that keeps foreign access stays reachable when international links are cut. Server: Domestic VPS → foreign exit (REALITY over TCP).

      Path (Relay chain): Your device → ISP filter → Relay → Border gateway → Exit server → Website. Censor sees A domestic connection; servers: 2 servers; delay: +1 relay hop (~2× RTT).

      Good: Your traffic never crosses the border directly Survives allowlists if the relay's data-centre keeps foreign access Domestic sites stay fast Watch out: Two servers to run The relay operator sees everything Extra latency

    2. 2nd: CDN ranges on the allowlist

      Some CDN ranges were allowlisted at times in Iran (Jan 2026). VLESS over XHTTP or WebSocket can ride them.

      Path (CDN-fronted): Your device → Censor → CDN edge → Origin server → Website. Censor sees HTTPS to a CDN; servers: CDN + server; delay: +2–3 RTT, longer path.

      Good: Hides your server's IP Can work under allowlists that include CDN ranges XHTTP can split upload and download paths Watch out: Slower start (≈800 ms first byte in a field test) The CDN sees request metadata and has rules (100 s idle timeout)

    3. Last resort: DNS tunnel · Psiphon

      DNS tunnels (dnstt, Slipstream) were the main tool that kept working, on some ISPs, in Iran's Feb–May 2026 blackout. Very slow. Psiphon (and its volunteer Conduit proxies) was the main method in late January.

      Path (DNS tunnel): Your device → Domestic resolver → Censor → Your DNS server → Website. Censor sees DNS lookups; servers: Resolver + server; delay: Very high.

      Good: Works when almost everything else is cut Uses the country's own DNS Watch out: Very slow Depends on a resolver that still reaches abroad

    Shutdowns change week to week. net4people has had no new field reports on what works in Iran since early August 2026 (as of 17 Oct).
